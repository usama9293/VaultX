# Security Policy

VaultX is a security-focused password manager project in active development for learning and portfolio purposes. It is not represented as production-secure and has not been independently audited.

## Reporting a Vulnerability

Do not disclose sensitive exploit details in a public GitHub issue. When GitHub private vulnerability reporting is enabled for the repository, use that mechanism. If it is unavailable, contact the project maintainers privately through a verified channel provided by the repository owner.

Please include only the information needed to understand and reproduce the report. Allow maintainers a reasonable opportunity to investigate before any public disclosure.

## Sensitive Information

Never submit real passwords, API keys, encryption keys, recovery secrets, personal data, or production credentials in issues, pull requests, logs, or test fixtures. If a secret is exposed, rotate or revoke it promptly and notify the maintainers privately.

## Authorized Testing

Security testing must be limited to systems and data you own or are explicitly authorized to test. Do not test against real users or production systems without written authorization.
